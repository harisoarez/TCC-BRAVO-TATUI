# Design Editorial / Pinterest (Salvo para Aprovação do Cliente)

Esta pasta armazena com segurança a versão da tela inicial desenvolvida com estilo editorial cinematográfico, inspirada na referência do Pinterest e com animações de revelação por rolagem (Scroll Reveal):

## Arquivos Salvos:
- `index.html`: Estrutura HTML da tela inicial com seção hero cinematográfica, 3 teasers na base e vitrine de destaques.
- `index.css`: Folha de estilo completa com a paleta escura (#0c1017), tipografia clássica, proporções de cards em retrato e animações fluídas.
- `heroBackground.jpg`: Imagem de fundo em alta definição gerada para o hero (piano de cauda e violoncelo no palco com iluminação âmbar/dourada).

## Como Restaurar no Projeto:
Se o cliente aprovar o design, basta copiar os arquivos de volta para a pasta pública:
1. `salvos/index.html` -> `public/pages/html/index.html`
2. `salvos/index.css` -> `public/pages/css/index.css`
3. `salvos/heroBackground.jpg` -> `public/pages/images/heroBackground.jpg`
