# Instituto Musical Bravo — Tatuí / SP

Projeto de landing page institucional de alto padrão estético para o **Instituto Musical Bravo**, sediado na Capital da Música (Tatuí/SP), com suporte a alternância instantânea entre a **Versão Editorial** e a **Versão TCC Adaptada**.

## 🔄 Botões de Alternância entre as Páginas

Para alternar entre as duas versões com 1 clique:
1. **No Cabeçalho (Navbar)**:
   * Na Versão Editorial: botão `Ver Versão TCC ⟶`
   * Na Versão TCC: botão `⟵ Ver Versão Editorial`
2. **Na Hero**:
   * Atalho direto para comparar os designs logo na primeira dobra.
3. **Pílula Flutuante no Canto Inferior Direito**:
   * Um botão flutuante em vidro escuro e dourado (`⇄ Alternar Página`) fica fixo na tela em qualquer rolagem para facilitar a comparação visual imediata.
